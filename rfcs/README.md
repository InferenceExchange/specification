# RFCs

Design proposals for substantial changes: protocol semantics, new
interfaces, new bindings, breaking schema changes.

## Process

1. Copy [0000-template.md](0000-template.md) to
   `NNNN-short-title.md`, using the next free number.
2. Open a pull request. Discussion happens on the PR.
3. Per [governance](https://github.com/InferenceExchange/.github/blob/main/GOVERNANCE.md),
   acceptance requires maintainer consensus. Merged RFCs record the
   decision; the specification documents in [../spec/](../spec/)
   remain the normative text.

Small fixes — typos, clarifications, non-normative editing — do not
need an RFC; open a pull request directly.
